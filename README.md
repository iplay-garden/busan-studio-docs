## 본사에 확인을 요청하는 항목

매뉴얼 [12장](docs/01_HEART_AI_STUDIO_사용매뉴얼.md)에 모아 두었습니다. 우선순위가 높은 것은 다음과 같습니다.

1. **MiniMax H3 라이선스** — 공개 가중치 라이선스가 대한민국을 제외 지역으로 정하고 있습니다. 국내용 라이선스(Comfy 상업 라이선스 또는 MiniMax 승인) 보유 여부 확인 전까지 부산은 MiniMax를 쓰지 않습니다.
2. **MASTER VIDEO GEN 출력 fps · 보간 여부** — 61프레임이 실제 몇 초인지(16fps면 약 3.8초, 보간 후 24fps면 약 5초).
3. **High · Low 체크포인트 조합** — 10/3 화면 기준 smoothMix(High) · Dasiwa(Low)가 의도된 조합인지.
4. **input_size** — 1280×768 → 960, 1024×576 → 1024 (본사 회신 반영). 그 밖의 해상도 기준.

답변이나 의견은 **Issues** 탭에 남겨 주시면 반영하겠습니다.

## 읽는 법

- 본문의 (공식)은 각 툴의 공식 문서, (본사)는 본사 회신·하달 자료, (사내)는 부산 자료, (현장 A·B·C)는 커뮤니티 실사용 보고입니다.
- ⚠ 표시는 아직 확정되지 않았거나 본사 확인을 기다리는 값입니다.
- 본문의 "운영계획서 ○-○"은 부산 내부 운영 문서의 조항 번호입니다. 이 저장소에는 포함하지 않았습니다.
- 툴 계정 정보는 어떤 자료에도 싣지 않습니다.
